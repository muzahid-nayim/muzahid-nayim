## About Me

I specialize in building websites and web applications from the ground up. On the frontend I use React, Next.js, and Tailwind CSS to create clean, fast, mobile-friendly interfaces. On the backend I use Django and Flask for the logic, databases, and APIs that power real functionality — not just static pages.

I care about writing clean code, meeting deadlines, and building things that actually solve a problem for the people using them.

- 🔭 Currently shipping freelance web projects and product builds

- 💬 Open to freelance work, collaborations, and junior developer roles
